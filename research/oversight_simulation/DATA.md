# Provenance and evaluation construction

No new source or model collection occurred. This stage reuses the exact inputs of
the frozen matched-qgm-v1 comparison, which had already been inspected during
pilot preparation. It is **not fresh held-out task evidence**. Model parameters
and the sensitivity matrix were frozen before the new comparative simulations.

| Layer | Origin | Role and limit |
|---|---|---|
| Tables and paragraphs | Real financial-report material represented in TAT-QA | Retained without invented values; not observed supervisory behavior |
| Original questions | Human-written TAT-QA questions | 36 distinct tasks across six source contexts, three packets |
| Reference annotations | Released benchmark labels | Used by the simulated outcome environment and independent scoring; unavailable to navigation policies |
| Initial drafts | Actual saved Qwen2.5-7B-Instruct generations, replica 0 | Seven joint-correct; five empty/unsupported displayed fields retained |
| Display projection | Existing uniform pilot parser | Includes restored answer displays; no change in frozen historical scoring |
| Task workers and arrivals | Constructed assignment and schedules | No workplace arrival or architecture-superiority claim |
| Reviewer timing and outcomes | Declared simulation functions and random draws | Uncalibrated assumptions; correct constructions use question-specific annotations |
| Incorrect constructed responses | Explicit simulation sentinel | Not a financial assertion, participant answer or new model output |
| Human evidence | None used or created | No participant/practice exports, ratings, quotations or identifiers |

The official source is [TAT-QA](https://github.com/NExTplusplus/tat-qa), pinned to
`870accc41953dcde885aabeb963d94aabdc0fbc3`, with
[Zhu et al., ACL-IJCNLP 2021](https://aclanthology.org/2021.acl-long.254/) as its
benchmark citation. Dataset attribution is CC BY 4.0; released code is MIT.
Licensing and original retrieval are inherited from the existing source audit,
not asserted as a new download. The original repository provenance lists hashes
for the raw data, README, license and evaluator. This study uses the previously
selected labeled test-gold contexts. Its raw source-file SHA256 is
`c4d08418359c1d76468dec420ee748a37f48c06b63cb8ec2766f19d5d314b597`.

`artifacts/oversight_simulation/provenance.json` links those historical records,
hashes the exact new input projection and lists every selected context/question.
`inputs.json` retains the full public source, original question, draft, parse
details and original generation call identity. No upstream dataset download is
needed for saved-output reproduction. Full benchmark files remain where the
historical collection placed them; they are not duplicated here.

Every original 12-question setting uses each packet under all five policies. The
original arrival schedule is retained. Six-question stress sets take the first
three questions per source under source order; larger loads union whole packets,
up to all 36 questions. A goal is never duplicated within a run. Burstiness,
interleaving and time budgets are constructed sensitivity conditions. The complete
selection rule is in MODEL.md and its frozen implementation in inputs.py.

The six source character counts are 1,120-1,750. Under the frozen clipping rule,
all source-size factors are 0.75, making first-visit orientation 0.75 times the
declared S coefficient. No within-sample source-size discrimination is established.

The packets have approximately matched public size characteristics, not identical
difficulty. Reliable report identifiers do not establish that these six contexts
come from independent reports or organizations. Rotations reuse sources. The
statistical unit for Monte Carlo error is the random seed, after averaging paired
packet rotations. This measures simulation integration error, not uncertainty over
the source population or a human population.

Historical evidence remains: 61/290 exact matches, 38 historical empty outputs,
and a separate pilot display projection with 31 empty/unsupported fields after
seven restorations. This study does not revise those numbers, annotations,
trajectories, estimators, publication-redaction provenance or manuscripts.
