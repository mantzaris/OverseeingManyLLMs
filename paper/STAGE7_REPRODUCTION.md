The frozen evaluation uses 18 experimental day blocks from one laboratory air
handler, 54 proposal/review pairs and 3,888 paired scheduling traces. Eight other
whole days supply development. The protocol was committed as
`5a5ae06a4cf311799214cac148bbbb7c2361f823` before evaluation calls.

## Saved outputs, no inference

From a clean checkout with Python 3.8+, NumPy, Matplotlib and LaTeX installed:

```bash
python3 -m pip install -r requirements-analysis.txt
bash scripts/replay_stage7.sh
python3 -m unittest discover -s tests -p 'test_hvac*.py' -v
```

The replay verifies all request/response attempts and frozen hashes, reconstructs
every scheduling trace, and recomputes the five main CSV tables and diagnosis
statistics in a temporary directory. Original measured planning times remain
unchanged. Plots use saved tables and selected sensor samples. The Matplotlib 3.1
compatibility wrapper uses the identical symmetric zero-centered normalization
and clarifies that a harmful review can produce abstention. It changes no score
or selected example. Both compiled PDFs are generated by `bash paper/build.sh`.

The manuscript class table is generated from
`artifacts/stage7_empirical/analysis/class_diagnostics.csv` by
`scripts/hvac_diagnostics.py`. PDFs and 300-dpi PNG previews are in
`artifacts/stage7_empirical/figures/`. Their sources are `plot_hvac.py`,
`plot_hvac_compat.py` and `hvac_diagnostics.py`.

## Measured source reconstruction

The complete external CSVs are excluded from Git. Download only the two pinned
measured files to a directory outside the repository:

```bash
python3 scripts/download_hvac.py --out /tmp/stage7_hvac_source
```

This checks the saved SHA-256 values against Figshare version 3 downloads.
`overseeing.hvac.prepare('/tmp/stage7_hvac_source')` reconstructs cases and source
checksums without writing them. Compare its returned cases to `cases.json`.
The saved cases include all selected one-minute signals and exact public summaries,
so analysis and figure reproduction do not depend on live download availability.
Source licensing is CC0 for this pinned Figshare record; attribution and the
inventory accompany the provenance manifest. Simulated collection files are
excluded. Measured laboratory signals must not be called occupied-building data.
